BBIT Library Management System – How to Run in VS Code 💻

Follow these steps to run the project on your laptop:

1. Install Java

- Install JDK 17 or newer.
- Check installation by opening CMD/Terminal and running:
  "java -version"
  "javac -version"

2. Install VS Code

- Download and install Visual Studio Code.
- Open VS Code.
- Go to Extensions ("Ctrl + Shift + X").
- Search for Extension Pack for Java by Microsoft and install it.

3. Open the Project

- Extract the project ZIP file, if required.
- Open VS Code.
- Go to File → Open Folder.
- Select the "LibraryManagementSystem" project folder.

4. Open the Terminal

Press Ctrl + ` to open the VS Code terminal.

Make sure the terminal is inside the main project folder (the folder containing "src").

5. Compile the Project

For Windows PowerShell, run these commands one by one:

First:

New-Item -ItemType Directory -Force out

Second:

$files = Get-ChildItem -Path src -Recurse -Filter *.java | ForEach-Object { $_.FullName }

Third:

javac -d out $files

6. Run the Application

java -cp out Main

The Library Management System login window should open.

7. Demo Login Credentials

Username: "admin"

Password: "admin123"

Important Notes:

- Use JDK 17 or newer.
- No MySQL or external libraries are required.
- The application uses Java Serialization for data storage.
- "library-data.ser" is created automatically in the working directory.
- Saved data is loaded automatically when you reopen the application.
- If you make changes to the source code, compile again before running.

That's it! Enjoy exploring the BBIT Library Management System!
